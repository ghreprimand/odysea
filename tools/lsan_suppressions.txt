# LeakSanitizer suppressions for third-party one-time initialization.
#
# fontconfig parses its XML configuration the first time a process touches the
# font database and deliberately keeps the parsed configuration allocated until
# process exit; it is reported as leaked because fontconfig installs no exit
# teardown. Every test process that resolves a font family trips it. The
# suppression is scoped to fontconfig frames, so leaks in this project's own
# code remain fatal.
leak:libfontconfig

# Rendering a real OpenGL scene graph under the sanitizer trips one-time
# allocations that the GPU driver keeps alive until process exit —
# driver-internal state from context creation. The driver module differs by
# vendor, so one entry per supported driver family: the NVIDIA proprietary
# core library, the Mesa Gallium drivers for AMD and Intel (older split
# radeonsi/iris/crocus modules and the merged libgallium), the Mesa software
# rasterizer used where no hardware context exists, and the Mesa GLX vendor
# and GL API dispatch libraries. Every pattern names a third-party module, so
# leaks in this project's own code remain fatal.
leak:libnvidia-glcore
leak:radeonsi_dri
leak:iris_dri
leak:crocus_dri
leak:swrast_dri
leak:libgallium
leak:libGLX_mesa
leak:libglapi

# The D-Bus session-bus message loader, touched by the Qt platform
# integration during a real-GL run, keeps its queued-message allocation
# alive until process exit. The suppression names the exact libdbus
# function rather than the whole client library, so an allocation leaked by
# project code inside a D-Bus dispatch callback remains fatal.
leak:_dbus_message_loader_queue_messages
